# Account Type Decision Checklist

- [ ] **출시 주체가 누구인가?** (개인 / 개인사업자 / 법인 / 비영리)
- [ ] **앱에 상업적 기능이나 결제가 포함되어 있는가?**
- [ ] **사업자/기업 상호로 스토어에 표기해야 하는가?**
- [ ] **Google Play 정책상 Organization 필수 카테고리인가?** (Health, Finance, Govt 등)
- [ ] **D-U-N-S 준비 여부 및 법인 서류 준비 상태 확인**
