### 설치 충돌 (0.1.11)

- **원인**: `applicationId`는 `im.balmi.app`으로 동일. 0.1.11 APK만 **다른 머신의 debug.keystore**로 서명됨 (0.1.8–0.1.10 Windows debug SHA1 `80:C1:…` vs 0.1.11 Linux debug SHA1 `6B:F9:…`). Android는 서명이 다르면 「기존 패키지와 충돌」로 덮어쓰기 거부.
- **조치**: `android/keystore/balmi-upload.jks` + `key.properties`로 **릴리스 업로드 키** 고정. 0.1.12+는 모두 동일 서명.
- **사용자**: 0.1.11 이하 설치 중이면 **앱 삭제 후** 0.1.12 설치. 0.1.12 이후 버전은 덮어쓰기 업그레이드 가능.

### GPS / 기록

- **실시간 페이스·속도 0**: Android가 마지막 GPS를 1Hz로 재송출하면 모션 필터가 정지 판정. 동일 픽스 클론은 거리·랩에 쓰지 않고, **고유 픽스만** 반영.
- **거리 과소 (현장 0.63km vs 8×600m≈4.8km)**: 클론 틱 + 약한 케이던스로 동결 + Android `speed=0`을 도플러로 오인. `speed=0`은 도플러 유효가 아님. 케이던스 약해도 실외 보행 거리는 끊지 않음.
- **GPS 공백**: 픽스가 **3초** 이상 오래되면 거리만 걸음×보폭으로 채움 (걷기 **0.72m**, 뛰기 **0.95m**). 공백 동안 쌓인 `uncountedStepM`은 다음 GPS 점프에서 빼서 **이중 가산 없음**. 지도 폴리라인은 공백을 메우지 않음 (정직한 갭).
- **`--'--"` 페이스**: 현재 페이스 없음 (GPS 대기 / 속도 0·정지). `formatPace`는 0.5km/h 이하에서 이 문자열.
- **정지 시 현재 속도 0**: accuracy 원 안 지터는 이동이 아님. **평균 속도 = 거리 / 이동 시간** (정지 구간 제외).
- **트랙 자동**: GPS 루프 둘레 약 **250–850m** (예: 600m 운동장)이면 랩 감지. 라이브 시트에 바퀴 수. 트랙 규격 후보에 500/600m 포함.
- **걷기↔뛰기 자동**: 기본 **≥8km/h를 8초**. 케이던스 140/15초 조건은 필수 아님. 주머니에서 케이던스가 약해도 속도로 전환. 라이브 UI: **걷기/뛰기** + **0바퀴**.

### UI

- 캔버스: 밝은 흰/회색. **고구마톤은 로고·버튼만**.
- 하단 독: 아이콘만 (크롬 라벨 제거). 기록 화면은 아이콘+숫자. 일시정지는 일시정지 아이콘, 종료는 **종료** 유지.
- 트랭글/산길샘은 **패턴 참고만**. 클론 아님. **네이버 지도 추가하지 않음** (사용자 금지). OSM 유지.
- 기록: 접는 스탯 시트, 리센터, 종 알림, 종료 확인 모달. 일시정지 → **종료 / 재시작**.
- 홈: 독 위에 종목 아이콘, 시작(재생)과 같은 크기 **68**. 롱프레스 원형 피커 — `activity_circle_picker`는 로컬 미커밋일 수 있음 (이 워크스페이스에는 파일이 없음).
- 워드마크 확대. GPS는 「강」이 아니라 **와이파이형 막대**. OSM OSD 배지는 지도 밖, 크레딧은 **더보기/설정**. 세션 상세 지도는 경로에 맞춤. **전체포인트 / 저품질 / 마지막동기화** 숨김.

### 식후 혈당 워킹 알림 (옵트인)

- 홈 제안 카드 + 설정 **건강 습관**. 앱 최초 온보딩에는 넣지 않음.
- 미니 온보딩 4단계. 디스클레이머는 **확인했어요** 버튼으로만 통과. 끄고 다시 켤 때도 재노출.
- 식사 기본 시각 08:00 / 12:30 / 19:00. 로컬 알림(`flutter_local_notifications` + 기존 FGS 기록). 서버 FCM 없음.
- 식사 시작 확인 → 30분 뒤 걷기 알림 → 기존 기록 파이프라인으로 15분. 최소 이동 50m.
- 진행 중 세션이 이미 15분·50m이면 중복 알림 없이 자동 완료. 하루 아침/점심/저녁 최대 3회.
- 중단은 부분 기록 + 「그래도 오늘 N분 걸으셨어요」. 놓치면 「괜찮아요, 다음 끼니에 다시 해봐요」.
- 완료 시 보너스 물주기 + **혈당지킴이** 배지. VASA 참여도(완료÷프롬프트)는 설정에만.
- **네이버 지도 없음.** 의료 진단/처방 대체 문구는 스펙 디스클레이머 그대로.

### 영역 (territory)

- Uber 공식 H3 라이브러리가 아니라 **H3 스타일 육각 그리드**. API 형태는 `pathToCells` / `polygonToCells`. 셀 id `{res}:{q}:{r}`.
- `TerritoryBoard`: occupy / reinforce / recapture.
- 존 롤업 해상도 **10 / 9 / 7 / 5**. **내 땅**에 헥스 오버레이.
- 나중에 공식 H3를 쓸 경우 **Apache 2.0** 고지. 이 날짜의 `main` 스냅샷에는 아직 헥스 엔진 파일이 없을 수 있음 (세션에서 합의·구현 방향).
